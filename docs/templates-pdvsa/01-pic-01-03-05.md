### 1.2. Estructura del Documento Normativo

#### Carátula / Portada
- Logotipo PDVSA (parte superior centro)
- Título: "NORMA PDVSA"
- Código: "PIC-01-03-05"
- Título completo: "CODIFICACIÓN DE PROYECTOS"
- Fecha de emisión / revisión
- Número de revisión (REV #)
- Clasificación de seguridad: "ESTRICTAMENTE CONFIDENCIAL" o "DOCUMENTO CONTROLADO"
- Código de clasificación documental CIED

#### Índice / Tabla de Contenido
1. Propósito
2. Alcance
3. Definiciones
4. Documentos a Consultar
5. Responsabilidades
6. Desarrollo
7. Anexos

#### Secciones Principales

**1. PROPÓSITO**
- Establecer un sistema único, uniforme y estandarizado de codificación para identificar proyectos, activos, instalaciones y documentos en PDVSA.

**2. ALCANCE**
- Aplica a todas las gerencias, filiales, contratistas y entes operativos de PDVSA que generen documentos técnicos.

**3. DEFINICIONES**
- Proyecto, Activo, Instalación, Código, Disciplina, Fase FEL, Documento Controlado, Expediente Técnico.

**4. DOCUMENTOS A CONSULTAR**
- PIC-01-01-01 (Sistema de Gestión de Proyectos)
- Normas CIED volumen correspondiente
- Estándares ISO 9001 aplicables

**5. RESPONSABILIDADES**
- **Gerente de Proyecto:** Asignar y controlar el uso de códigos
- **Coordinador de Documentación:** Velar por la correcta codificación
- **Contratistas:** Cumplir con la codificación estándar

**6. DESARROLLO — SISTEMA DE CODIFICACIÓN**
```
AABBCCDDEE     Identificación del Proyecto (10 dígitos)
AA             Filial o negocio
BB             ACE (Área Corporativa de Explotación)
CC             Área geográfica (Acrónimo CIED-CM-01)
DD             Año de inicio del proyecto
EE             Consecutivo del proyecto por año/filial

FFGHI          Identificación de la Actividad (5 dígitos)
FF             Instalación (Anexo D de la norma)
G              Subproyecto (0-9)
H              Fase del proyecto (V/C/D/I/O)
I              Clasificación de la Actividad (1-6)

JKLLMMM        Identificación del Documento (7 dígitos)
J              Disciplina técnica
K              Tipo de documento (D=Documento, P=Plano)
LL             Producto (Anexo E/F)
MMM            Número correlativo (001-999)
```

**7. ANEXOS**
| Anexo | Contenido |
|-------|-----------|
| **A** | Formato Carátula Oficial de Documento |
| **B** | Formato de Hoja Control de Revisiones |
| **C** | Catálogo Filial/Negocio (AA), ACE (BB) y Área Geográfica (CC) |
| **D** | Lista de Instalaciones (FF) |
| **E** | Productos: Documentos (Disciplina J, Tipo K=D) |
| **F** | Productos: Planos (Disciplina J, Tipo K=P) |
