#### SECCIONES DEL DOCUMENTO

**SECCIÓN 1 — INFORMACIÓN GENERAL DEL PROYECTO**
| Campo | Tipo | Requerido | Descripción |
|-------|------|-----------|-------------|
| Nombre del Proyecto | Texto | ✓ | Nombre completo del proyecto |
| Código PDVSA | Código | ✓ | Según PIC-01-03-05 |
| Ubicación | Texto | ✓ | Estado, Municipio, Coordenadas |
| Descripción del Proyecto | Texto largo | ✓ | Alcance general de la obra |
| Contrato N° | Texto | ✓ | Número de contrato |
| Presupuesto Asignado | Monto | ✓ | Presupuesto en USD |
| Duración Estimada | Fechas | ✓ | Fecha inicio / Fecha fin |
| Cliente / Filial | Texto | ✓ | PDVSA Gas, PDVSA E&P, etc. |

**SECCIÓN 2 — ALCANCE DEL PLAN DE CALIDAD**
- 2.1 Objetivo del Plan de Calidad
- 2.2 Campo de Aplicación
- 2.3 Exclusiones (si aplica)
- 2.4 Referencias Normativas (PDVSA C-02, ISO 9001, ASME, API, ASTM)

**SECCIÓN 3 — TERMINOLOGÍA Y DEFINICIONES**
| Término | Definición |
|---------|-----------|
| QA | Aseguramiento de la Calidad |
| QC | Control de la Calidad |
| ITP | Plan de Puntos de Inspección |
| NDT | Ensayos No Destructivos |
| WPS/PQR | Welding Procedure Specification / Procedure Qualification Record |
| No Conformidad (NC) | Desviación respecto a requisitos |
| Acción Correctiva (AC) | Acción para eliminar causa de NC |

**SECCIÓN 4 — ORGANIGRAMA DE CALIDAD**
- 4.1 Estructura Organizativa del Proyecto
- 4.2 Roles y Responsabilidades de Calidad
  - Gerente de Proyecto (Contratista)
  - Líder QA/QC
  - Inspector de Soldadura (CWI)
  - Inspector NDT (Nivel II / III)
  - Inspector de Materiales
  - Inspector de Recubrimientos
  - Coordinador de Documentación Técnica (Dossier)
  - Representante PDVSA (Inspección Cliente)

**SECCIÓN 5 — REQUISITOS DE CALIDAD POR DISCIPLINA**
- 5.1 Civil / Estructuras
  - Ensayos de concreto (rotura de probetas)
  - Control de excavaciones y rellenos (Próctor, densidad de campo)
  - Tolerancias dimensionales
- 5.2 Mecánica / Tuberías
  - Control dimensional de tuberías (DN, cédula, material)
  - Calificación WPS/PQR según ASME IX
  - Ensayos NDT (RT, UT, PT, MT)
  - Prueba hidrostática (presión, duración, criterios)
  - Control de torque en bridas (ASME PCC-1 / PDVSA 906)
- 5.3 Instrumentación y Control
  - Calibración de instrumentos
  - Pruebas de lazo (loop check)
  - Certificados de calibración
- 5.4 Electricidad
  - Pruebas de resistencia de aislamiento (Megger)
  - Continuidad de tierra
  - Pruebas de funcionamiento
- 5.5 Recubrimientos y Pintura
  - Perfil de anclaje, espesor de película seca, adherencia
  - Inspección de recubrimientos según PDVSA N-203 / N-204

**SECCIÓN 6 — CONTROL DE DOCUMENTOS Y REGISTROS**
| Tipo de Documento | Formato | Código | Retención |
|-------------------|---------|--------|-----------|
| ITP (Inspection Test Plan) | Tabla | ITP-XXX-001 | Hasta cierre |
| Reporte NDT | Informe | NDT-RT-001 | 10 años |
| Certificado de Materiales | Digital | CM-001 | 10 años |
| WPS / PQR | Ficha | WPS-001 | Vida del activo |
| Matriz de Calidad | Tabla | MC-001 | Hasta cierre |
| Dossier de Calidad | Compendio | DC-001 | Vida del activo |

**SECCIÓN 7 — CONTROL DE NO CONFORMIDADES Y ACCIONES CORRECTIVAS**
- 7.1 Identificación y reporte de NC
- 7.2 Clasificación de NC (Crítica / Mayor / Menor)
- 7.3 Procedimiento de disposición de NC (Reparación / Reemplazo / Concesión)
- 7.4 Seguimiento y cierre de AC
- 7.5 Análisis de tendencias y mejora continua

**SECCIÓN 8 — AUDITORÍAS INTERNAS**
- 8.1 Programa de auditorías internas
- 8.2 Checklist de auditoría
- 8.3 Notificación y reporte de hallazgos
- 8.4 Cierre y seguimiento

**SECCIÓN 9 — CONTROL DE MATERIALES Y TRAZABILIDAD**
- 9.1 Recepción e identificación de materiales
- 9.2 Certificados de calidad (Mill Test Reports, MTR)
- 9.3 Trazabilidad de materiales críticos
- 9.4 Almacenamiento y preservación

**SECCIÓN 10 — CIERRE DE CALIDAD Y DOSSIER**
- 10.1 Contenido del Dossier de Calidad
- 10.2 Revisión final y aprobación de PDVSA
- 10.3 Entrega formal y acta de recepción
